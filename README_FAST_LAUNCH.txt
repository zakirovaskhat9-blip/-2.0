LT6MS LAUNCHER - FAST DOWNLOAD / STABLE START PATCH

Это дополнение к ТЕКУЩЕМУ репозиторию GitHub. Оно не заменяет весь проект.

Как установить:
1. Распакуй ZIP.
2. В GitHub открой репозиторий zakirovaskhat9-blip/-2.0.
3. ЗАМЕНИ 3 файла в папке Enchanted/Core/ на файлы из архива.
   Не удаляй существующие client-mod, Skins.java, XAML, workflow и другие файлы.
4. Сделай Commit changes.
5. Открой GitHub Actions -> Build LT6MS Launcher -> новый запуск.
6. После успеха скачай артефакт LT6MS-Launcher с EXE.

Новые ограничения времени:
- 3 секунды на ответ от одного зеркала/сервера Mojang/Fabric.
- 150 мс между переключениями сетевых источников.
- 5 секунд без прогресса после начала сетевой работы с последующим повтором через 250 мс.
- До 8 секунд на первичную локальную подготовку, чтобы не отменять работу с файлами слишком рано.
- 5 секунд без данных при скачивании мода, переключение через 250 мс.
- Локальный кэш модов и зависимостей сохраняется, повторная загрузка не требуется при исправных файлах.
- При ошибке быстрого запуска происходит попытка восстановления файлов игры.
- Логирование преждевременного закрытия Minecraft в launcher.log и game-output.log.

На компьютере настройки остаются в %APPDATA%\.enchanted
Ограничение: Windows/.NET и Minecraft в этой среде не запускались.
Проверка после сборки нужна. Скорость и успешность запуска зависят от подключения и состояния игровых файлов.
