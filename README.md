# LT6MS лаунчер — исходники для GitHub

Это исходники LT6MS лаунчера для Minecraft. **ZIP не является готовым EXE**.

## Загрузка на GitHub

1. Распакуйте ZIP **на компьютер** (GitHub не распаковывает загруженный ZIP сам).
2. Загрузите **всё содержимое** папки распаковки в корень репозитория, сохраняя `.github/workflows`, `Enchanted`, `client-mod`, `server` и `tools`.
3. В GitHub откройте **Actions → Build LT6MS Launcher → Run workflow** (либо дождитесь сборки после push).
4. После успешной сборки скачайте артефакт **LT6MS-Launcher**, внутри будет `LT6MS Launcher.exe`.

## Исправления

- Для Minecraft **1.21.11** в `Skins.java` заменён `net.minecraft.resources.ResourceLocation` на `net.minecraft.resources.Identifier` во всех пяти местах (импорт, поле, локальные переменные и вызов фабрики). Это устраняет ошибки `cannot find symbol ResourceLocation` из присланного лога.
- Переименовано видимое название окна и интерфейса, имя собираемого EXE, сведения о продукте и GitHub Actions в **LT6MS лаунчер**.
- Лаунчер по-прежнему использует внутренний C# namespace `Enchanted`, папку настроек `.enchanted`, а Fabric-мод — id `enchanted_client`. Это **специально**, чтобы не пропали настройки, сохранённые скины и установленный мод.
- Команда `/eskin <ник>` и загрузчик скинов сохранены. Старые визуальные модули остаются удалёнными.

## Проверки и ограничения

- Статически проверены структура файлов, JSON, XML/XAML и наличие исправлений в Java-коде и workflow.
- Полный `gradle build` и `dotnet publish` в этой среде **не выполнялись**: нет Gradle, .NET SDK и сетевого доступа для их загрузки. Поэтому гарантировать успешную сборку GitHub Actions нельзя.
- Если Actions снова падает, откройте шаг **«Собрать клиентский мод»** или **«Собрать лаунчер»** и пришлите первые строки с `error:`. Не ориентируйтесь только на сопутствующую ошибку `build/libs`.
