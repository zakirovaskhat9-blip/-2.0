# LT6 + LT6MS Launcher — для GitHub

- Клиентский Fabric-мод называется **LT6** (`id: lt6`, `dev.lt6.client`).
- Windows-лаунчер — **LT6MS Launcher**. Внутреннее имя его .NET проекта `Enchanted` сохранено для совместимости; **это не старый мод**.
- Версия модификации: **Minecraft 1.21.11**. На 1.21.4 визуальный мод не устанавливается.
- GUI в игре: **правый Shift** по умолчанию, настраивается в «Управление → Назначение клавиш → LT6». Запасная клиентская команда `/lt6`.
- Скины: `/eskin <ник>`, `/eskin reset`; новый путь конфигурации `lt6-skins.json`. При первом запуске используется старая конфигурация, если новая отсутствует.
- Sky: только 6 новых присланных панорам, 36 граней, видео не добавлено.

## Как отправить в GitHub

1. Распакуй архив и загрузи содержимое `-2.0-main` в **корень** репозитория, включая скрытую папку `.github`.
2. GitHub не удаляет старые файлы при загрузке через браузер. **Удали из репозитория старую папку** `client-mod/src/main/java/dev/enchanted`, старый путь `client-mod/src/main/resources/assets/enchanted_client` и файл `client-mod/src/main/resources/enchanted-client.mixins.json`. Для надёжности workflow дополнительно удаляет эти пути на runner перед сборкой.
3. Запусти `Actions → Build LT6MS Launcher`, после успешной сборки скачай `LT6MS-Launcher` в разделе Artifacts.
4. Если возникает ошибка, пришли лог с первой строкой `error:` или `Caused by:` и файлы `%APPDATA%\.enchanted\launcher.log`, `%APPDATA%\.enchanted\game-output.log`.

## Проверки и ограничения

- Структура ZIP, манифест Fabric, YAML, JSON и XML проверены.
- Для полноценной сборки необходимы Fabric Gradle и .NET SDK на Windows runner. Успешная компиляция и запуск игры **не подтверждены локально**.
- Старые настройки C#-лаунчера находятся в `%APPDATA%\.enchanted`: сохранено намеренно, чтобы не потерять игру/скины/загрузки.
- Постобработка и Custom Sky используют экспериментальный рендеринг: при проблемах в рантайме понадобится лог игры.
