# LT6 — ровное вращение Target ESP

Исправлен модуль Target ESP (Minecraft 1.21.11).

* Четыре одинаковых неоновых шеврона вращаются как один узор, без точки посередине.
* Постоянная угловая скорость в реальном времени (не привязана к игровым тикам и FPS), без ускорения и замедления.
* Убрана пульсация яркости, которая создавала ощущение неритмичного движения.
* Масштаб зависит от высоты и расстояния модели в 3D. При вращении/наклоне камеры больше не пересчитывается по двум непостоянным экранным координатам ног и головы.
* Настройка **Оборот за** в Target ESP: от 1,2 до 8 секунд, по умолчанию 3 секунды. При изменении скорости текущий угол сохраняется без скачка.
* Остальные модули и ресурсы оставлены без изменений.

## Проверка

Полная сборка Fabric и тест на экране Minecraft 1.21.11 необходимы. Архив содержит исходники для GitHub, а не готовый JAR/EXE. При необходимости точного совпадения с Nursultan нужна короткая запись вращения из Nursultan (на статичной цели); без неё нельзя достоверно воспроизвести скорость/фазы эффекта на 100%.
