# LT6MS — кнопка «Моды» в Minecraft

## Что добавлено

- В список модов лаунчера добавлен `modmenu` (TerraformersMC Mod Menu).
- Mod Menu добавляет кнопку **«Моды»** на главный экран Minecraft и список установленных модов с поиском, информацией и доступными кнопками настроек.
- Для Minecraft **1.21.11** подбирается Mod Menu **17.0.1**, для **1.21.4** — **13.0.4** (по состоянию на подготовку архива). Лаунчер автоматически выбирает версию по API Modrinth или зеркалу.
- LT6 получает собственную иконку в списке Mod Menu. GUI LT6 по-прежнему открывается левым Shift (именно при нахождении в игре).
- Всего обязательных внешних модов — 8, плюс LT6 для 1.21.11; установленный предел остаётся **12 JAR** с учётом обязательных внешних зависимостей. Пользовательские моды лаунчер не удаляет.

## Как установить через GitHub

1. Распакуй ZIP и залей **содержимое** папки `-2.0-main` в корень репозитория.
2. GitHub → Actions → Build LT6MS Launcher → Run workflow.
3. Скачай `LT6MS-Launcher` из Artifacts, запусти EXE и выбери Minecraft 1.21.11.
4. Лаунчер должен скачать `modmenu-17.0.1.jar` вместе с остальными модами. На главном экране игры появится кнопка **Mods/Моды**.

### Чтобы мод скачивался заранее с GitHub Release

Запусти Actions → **Fetch mods** → Run workflow с обновлёнными настройками по умолчанию. Это создаст/обновит Release `mods-1.21.11` (и `mods-1.21.4`) с `modmenu` в `index.json`.

Если загрузка Mod Menu не удалась из-за сети — проверь `%APPDATA%\.enchanted\launcher.log` и список `...\mods\`. В 1.21.11 рабочая папка: `%APPDATA%\.enchanted\game\mods`.

## Проверка

Ожидается JAR `modmenu-*.jar` (название версии может отличаться, поскольку выбирается актуальная совместимая). Установка через официальный Modrinth/зеркало; файл Mod Menu не вложен в ZIP. Это исходники проекта, а не собранный EXE.

## Ограничения

Mod Menu показывает параметры модов, только когда сами моды их предоставляют. Визуальное меню LT6 по-прежнему открывается левым Shift. Успешную сборку и отображение кнопки нужно проверить на Windows в GitHub Actions/Minecraft.
