# LT6 — переработка рендера (Minecraft Fabric 1.21.11)

**Это исходники, не готовый проверенный EXE.** Для релиза нужна зелёная сборка в GitHub Actions и проверка в Minecraft: Gradle/Fabric и Windows/.NET нельзя было запустить в среде подготовки.

## Что изменилось

- Удалён старый, неработающий Cubemap/`SkyPano` и связанные Java-классы. Шесть ваших изображений теперь входят в лаунчер как **шесть OptiFine/Skyboxify ресурс-паков**, без чужих/старых наборов.
- В `LT6 > Custom Sky` выбор пресета переключает набор ресурсов Minecraft через `PackRepository`, сохраняет выбранный набор в настройках и перезагружает ресурсы. Облака отключаются при включённом Custom Sky. Наличие мода **Skyboxify** обязательно для показа нестандартного неба.
- В `LT6 > Contrast` отрицательные значения сводят изображение к чёрно-белому, положительные увеличивают насыщенность и локальный контраст. Температура цвета работает через **GPU post shader**, а не через прозрачные цветные прямоугольники.
- Пост-эффект использует основную глубину кадра и не меняет пиксели неба (глубина ≈ 1). При включённом Custom Sky постобработка LT6 временно отключается, чтобы исключить перекраску пользовательских панорам и конфликты с Skyboxify.
- 231 готовых профилей post-effect (контраст с шагом 10 и теплота с шагом 20). Переключение из меню LT6; профили дискретные, хотя положение ползунка может задаваться точнее. Gamma/яркость остаётся штатной настройкой Minecraft.
- Уменьшены ползунки и масштабированные заголовки, усилены Jump Circles, уменьшено дрожание Target ESP, сохранены Hit Color и FPS. GUI — Right Shift (`/lt6` — запасной способ).
- GitHub Actions добавляет отдельный артефакт LT6-Mod-JAR и запускает предварительную проверку ресурсов/шейдеров `tools/validate_lt6.py`.

## Как опубликовать

1. Распаковать этот архив и загрузить **содержимое** папки `-2.0-main` в корень GitHub-репозитория. Убедиться, что `.github/workflows/build.yml` обновился.
2. Запустить **Build LT6MS Launcher** в Actions. Зелёные шаги означают успешную компиляцию, но не заменяют тестов в игре. В Artifacts должны появиться `LT6-Mod-JAR` и `LT6MS-Launcher`.
3. Запустить Minecraft **Fabric 1.21.11** через новый EXE. В Mod Menu должен отображаться LT6, а в `mods` лежать `lt6.jar`.
4. Открыть `/lt6` либо правый Shift (перепривязку проверять через Настройки → Управление → LT6). Проверить включение контраста и фильтра.
5. Проверить Custom Sky: убедиться, что установлен Skyboxify и подключён один из шести паков. Выбрать нужный в LT6, выйти из меню и дождаться перезагрузки ресурсов. Тестировать в мире, не на заставке Minecraft.
6. Провести отдельные тесты Hit Color (получение урона целью), Jump Circles (прыжок/приземление), Target ESP (приближение и отдаление от цели), FPS Counter.

## Ограничения и диагностика

- Новые шейдеры и смена ресурс-паков ещё **не проверены в реальной игре**. Если Minecraft пишет о невалидном post-effect или mixin, прикрепите `.minecraft/logs/latest.log` целиком и лог GitHub Actions со строками `error:` — по ним можно исправить точный метод/API, не угадывая.
- Другие моды, использующие post-effects, имеют приоритет: LT6 намеренно не вытесняет их постобработку, чтобы не ломать рендер.
- При отключённом Custom Sky цветовой фильтр защищает только пиксели с глубиной неба ≈ 1; сторонние шейдерпаки могут использовать другую глубину.
- `ShaderManager` может компилировать профиль при первом его включении; первое переключение может быть медленнее следующих.
- Для высокого качества текста GUI понадобится отдельный масштабируемый font renderer (этот этап ещё не завершён). Не заявляется, что интерфейс полностью заменён на векторный.
- Установка модов и Skyboxify зависит от доступности Modrinth/зеркал; 12 JAR-файлов — ограничение лаунчера.

## Полезные файлы

- `client-mod/src/main/java/dev/lt6/client/ColorFX.java` — включение/сброс GPU post-effects.
- `client-mod/src/main/java/dev/lt6/client/mixin/LT6PostEffectBridge.java` — invoker для `GameRenderer.setPostEffect`.
- `client-mod/src/main/resources/assets/lt6/shaders/post/grading.fsh` — настоящий GLSL shader.
- `client-mod/src/main/resources/assets/lt6/post_effect/grading/*.json` — 231 параметризованный профиль.
- `client-mod/src/main/java/dev/lt6/client/SkyPacks.java` — переключение наборов через API Minecraft.
- `Enchanted/sky_packs/LT6_*.zip` — 6 текстур-паков с присланными вами развёртками.
