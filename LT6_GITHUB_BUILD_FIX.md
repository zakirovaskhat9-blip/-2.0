# LT6MS Launcher + LT6 — исправление GitHub Actions

Исправлено по логу `SkyLib.scan()` (ошибка в `EnchantedScreen.java`) и старой маске имени JAR.

- Старый `EnchantedScreen.java` заменён минимальной совместимой заглушкой, наследующей `LT6Screen`: ошибки `SkyLib.scan()` больше нет. Настоящий GUI — `LT6Screen.java`, вызывается через `LT6Keys.java` (правый Shift).
- Старый неиспользуемый `EnchantedClient.java` заменён заглушкой. Точка входа `fabric.mod.json`: `LT6Client`.
- `SkyLib` теперь использует только 6 присланных наборов неба. В ZIP 36 PNG-граней (по 6 на панораму). В workflow дополнительно удаляются лишние старые PNG на сервере сборки, если они остались в репозитории.
- `.github/workflows/build.yml` ищет `lt6-*.jar`, пропуская `sources/dev/javadoc` и копирует в `Enchanted/client_mod/lt6.jar`.
- Сборка теперь останавливается при ошибке Gradle, отсутствии JAR, ошибке dotnet или отсутствии EXE. Это предотвращает ложный успешный результат без артефакта.
- В `mods.yml` в качестве набора по умолчанию перечислены 7 основных модов; лимит установки в лаунчере — 12 JAR с учётом обязательных зависимостей и LT6.
- Система скинов и команда `/eskin` сохранены.

## Как загрузить

Распаковать ZIP, зайти внутрь `-2.0-main` и загрузить **содержимое** в корень репозитория, заменив существующие файлы. Можно через веб-интерфейс GitHub: заглушки старых Java-файлов перезапишут их, а workflow выкинет старые изображения неба из итогового JAR. Само содержимое репозитория при веб-загрузке не очищается: для окончательного удаления старых PNG из Git используйте GitHub Desktop/Git или удалите их в браузере. Перед заменой сохраните свои правки.

Сборка: GitHub Actions → Build LT6MS Launcher. После успешной сборки в Artifacts должен появиться `LT6MS-Launcher` с `LT6MS Launcher.exe`.

## Ограничения проверки

В этой среде нет установленного Gradle и .NET SDK с зависимостями Fabric; полная компиляция и игровой запуск не выполнялись. Успешное прохождение GitHub Actions и работа Custom Sky в Minecraft пока не подтверждены. `SkyPano` использует совместимость с рендерером через reflection, которую нужно проверить в игре.
