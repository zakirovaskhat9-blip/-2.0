# LT6MS лаунчер — исправление ошибок сборки

- В `Skins.java` и `SkinMixin.java` заменены вызовы `GameProfile.getName()` на `GameProfile.name()` для Authlib, поставляемой с Minecraft 1.21.11.
- Из `client-mod` удалены оставшиеся, неиспользуемые исходники старого GUI, ESP, HUD, Custom Sky и его текстуры. `fabric.mod.json` и конфигурация mixin по-прежнему подключают только skin-мод.
- В `build.yml` после ошибки `gradle build` шаг завершается сразу, а отсутствующий JAR выводит отдельную понятную ошибку. Раньше лишняя ошибка `build/libs` скрывала основную причину.
- `mods.yml`: семь основных модов вместо старого списка из 18 (зависимости загружаются отдельно). Сам лаунчер ограничивает число JAR до 12.

- После получения полного лога с 5 ошибками `cannot find symbol ResourceLocation` для 1.21.11 во всех вхождениях `Skins.java` используется `Identifier` с тем же методом `fromNamespaceAndPath`.
- Приложение, EXE и GitHub Actions переименованы в LT6MS лаунчер.

**Проверка:** XML/XAML, JSON, YAML, и исправления проверены статически. Полная компиляция Java и C# не выполнена в этой среде (нет Gradle, .NET SDK и сети). Если GitHub Actions по-прежнему падает, нужен лог первого шага с `error:`.
