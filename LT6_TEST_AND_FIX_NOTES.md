# LT6 + LT6MS: проверка сборки и запуска

## Что исправлено

- LT6 отображается в настройках управления Minecraft и по умолчанию назначен на **правый Shift**.
- Запасной способ открыть GUI — команда `/lt6` в чате после входа в мир.
- EXE не может успешно собраться без встроенного `lt6.jar`; JAR проверяется на `fabric.mod.json` и `LT6Client.class`.
- При запуске 1.21.11 LT6 распаковывается в `game/mods/lt6.jar`; при повторном запуске идентичный JAR не перезаписывается.
- Устаревшие копии с именем `enchanted-client*.jar` удаляются, чтобы избежать дублирующей загрузки старого LT6.
- Если CmlLib не передаст параметр `--gameDir`, лаунчер добавит его сам, чтобы Fabric видел папку `mods`.
- Если Fabric API не установился, лаунчер сообщит об этом вместо запуска игры со сломанными зависимостями.
- GitHub Actions проверяет содержимое JAR и загружает EXE как артефакт.

## Как диагностировать

1. GitHub → Actions → **Build LT6MS Launcher** → успешный запуск; скачай **LT6MS-Launcher**.
2. Проверь, что выбран Minecraft **1.21.11**. Для 1.21.4 текущий LT6 не предусмотрен.
3. Запусти Minecraft, открой **Моды**: LT6 должен быть в списке.
4. В игре: Настройки → Управление → Назначение клавиш → **LT6** → **Открыть GUI**. Если раньше была сохранена привязка левого Shift, нажми **Сбросить**.
5. Нажми **правый Shift** или введи `/lt6` в игровом чате.
6. В `%APPDATA%\.enchanted\launcher.log` проверь сообщение `LT6 проверен:` и путь `game/mods/lt6.jar`.
7. В `%APPDATA%\.enchanted\game-output.log` проверь `LT6 client initialized`. Если записи нет, проверь `latest.log` или `crash-reports` игры.

## Ограничения проверки

ZIP и метаданные проверены локально, но в этой среде отсутствуют Gradle/Fabric зависимости,
.NET SDK и Windows Minecraft. Успешная компиляция и работа всех визуальных эффектов не доказаны.
Если сборка или запуск не удались, пришли ошибки из GitHub Actions / `launcher.log` / `game-output.log`.

**При обновлении через сайт GitHub важно вручную заменить `.github/workflows/build.yml`**:
скрытая папка `.github` может не попасть в загрузку, если загружать файлы не из корня.
