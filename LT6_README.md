# LT6 Visuals — Minecraft Fabric 1.21.11

Этот проект собирает встроенный в LT6MS Launcher мод **LT6**. Он устанавливается автоматически из EXE на Minecraft 1.21.11.

## Управление
- **Правый Shift** — GUI LT6.
- GUI: Visuals / HUD / Style; переключатели и параметры сохраняются в `config/lt6.json`.
- `/eskin Ник` — локальный скин по имени, `/eskin reset` — сброс.

## Модули
- FPS Counter (HUD).
- Target ESP (Nursultan Square / Celestial Corners): экранная рамка на последней атакованной живой цели; не показывает сквозь стены.
- Hit Color: цветные частицы вокруг цели при атаке (не замена текстуры самой модели).
- Jump Circles: кольцо цветных частиц при взлёте и приземлении.
- Brightness: gamma Minecraft с восстановлением исходного значения.
- Color Filter, Contrast: облегчённая экранная тонировка, **отключается целиком при активном Custom Sky**, чтобы не перекрашивать небо. Это не полноценный selective world shader.
- Custom Sky: шесть новых пользовательских панорам 3x2 (по шесть лиц); старых пресетов в архиве нет. При включении мод временно отключает облака и подавляет солнце/луну (через mixin); после отключения восстанавливает настройку облаков.

## Важно о Custom Sky
Это начальная реализация, использующая ванильный CubeMapRenderer в рендер-проходе неба. На отдельных видеокартах и сборках Minecraft возможно несовпадение render-пайплайна; если оно обнаружится, Custom Sky автоматически вернёт ванильный рендер и напишет ошибку в latest.log.
Текстуры преобразованы из изображений, которые прислал пользователь, без добавления старых панорам.

## Сборка / GitHub Actions
1. Распаковать содержимое `-2.0-main` в корень репозитория GitHub.
2. Запустить workflow `Build LT6MS Launcher`.
3. Он сначала собирает `client-mod/build/libs/lt6-1.0.0.jar`, помещает в `Enchanted/client_mod/lt6.jar`, после этого собирает EXE.
4. Скачать Artifacts → `LT6MS-Launcher`.

**Здесь сборка Gradle / dotnet не запускалась:** в среде нет Gradle и .NET SDK, поэтому успех компиляции и работы в Minecraft пока не подтверждён.
